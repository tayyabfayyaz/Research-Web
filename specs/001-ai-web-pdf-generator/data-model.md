# Data Model: AI Web Intelligence With PDF Generator

## Entities

### ResearchTask
Represents the lifecycle of a single URL analysis.

| Field | Type | Description |
|-------|------|-------------|
| id | UUID | Unique identifier |
| url | String | Input website URL |
| status | Enum | PENDING, SCRAPING, ANALYZING, GENERATING, COMPLETED, FAILED |
| error_message | String | Nullable error details |
| created_at | DateTime | Timestamp of request |
| updated_at | DateTime | Last status change |

### ResearchDocument
The structured output generated by AI.

| Field | Type | Description |
|-------|------|-------------|
| id | UUID | Unique identifier |
| task_id | UUID | Reference to ResearchTask |
| summary | String | Executive Summary (Section 1) |
| insights | List<String>| Key Insights (Section 2) |
| content | String | Extracted & Cleaned Content (Section 3) |
| validation | String | Extended Validation (Section 4) |
| risks | String | Risks & Limitations (Section 5) |
| comparison | String | Comparison with alternatives (Section 6) |
| pdf_url | String | Path to the stored PDF file |

## Relationships
- **ResearchTask** (1) --- (1) **ResearchDocument**
- **ResearchTask** has one-to-one mapping to the final document once completed.

## State Transitions
1. **PENDING**: User submits URL.
2. **SCRAPING**: Playwright is active.
3. **ANALYZING**: Gemini is processing the text.
4. **GENERATING**: Puppeteer is creating the PDF.
5. **COMPLETED**: PDF stored and link ready.
6. **FAILED**: Any error during the above steps.
